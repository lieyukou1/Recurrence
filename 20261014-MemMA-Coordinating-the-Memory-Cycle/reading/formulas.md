## 核心公式

### Eq.(1) —— Meta-Thinker 的两类指导


g_t^S~π_p(· | c_t, M̄_{t-1}) ; g_{q,h}^R~π_p(· | q, E_h, U_h, M̄_T)


- 出处：`p.4` / §4.1 Eq.(1)
- 含义：同一个 planner 输出**相位相关**的两种指导——构造期看"当前块 + 记忆有界视图"，检索期看"查询 + 已累积证据 + 查询历史 + 记忆有界视图"。
- 作用：g_t^S 给出一组 focus point（信息重要性、与既有条目的冗余、潜在冲突）；g_{q,h}^R 是对 E_h 的 critique，返回 `ANSWERABLE` 或 `NOT-ANSWERABLE` + 缺失诊断。

### Eq.(2) —— Memory Manager 的原子编辑


a_t^S~π_s(· | c_t, M̄_{t-1}, g_t^S) ; M_t=APPLY(M_{t-1}, a_t^S)


- 出处：`p.5` / §4.1 Eq.(2)
- 含义：记忆管理是**逐次原子编辑**（一次只做一个动作），g_t^S 的作用是让 π_s 去噪、整合冗余、在源头解决冲突，而不是无脑 append。
- 关键性质：π_s 与存储后端解耦（backend-agnostic），可包在 LightMem、A-Mem 等实现外层。

### Eq.(3) —— Query Reasoner 的 Refine-and-Probe 迭代


u_{h+1}~π_r(· | U_h, E_h, g_{q,h}^R) ; E_{h+1}=E_h∪SEARCH(M_T, u_{h+1})


- 出处：`p.5` / §4.1 Eq.(3)
- 终止条件：π_p 判 `ANSWERABLE`，或预算 H 用尽。
- 要点：每一步细化都**瞄准 π_p 诊断出的具体缺口**，因此是"正交取证"而非"近似重复改写"。

### Eq.(4) —— Answer Agent 出答案


ŷ(q)=F_{π_a}(q, E(q)) ; E(q)=E_H


- 出处：`p.5` / §4.1 Eq.(4)
- 实验设定：π_a **全程冻结为 GPT-4o-mini**，以解耦"答案生成能力"与"记忆质量"——这样增益才能归因于记忆周期协调，而非 π_a 的参数知识。

### Eq.(5) —— 探针集合成


Q_τ={(q_j, y_j)}_j=1^J


- 出处：`p.5` / §4.2 Eq.(5)
- 含义：每个 (q_j,y_j) 是扎根于当前会话 s_τ 与其相关历史上下文 M̄_{τ-1} 的**合成**问答对；三类覆盖：单会话事实召回、跨会话关系推理、时间推理。
- 意义：把"延迟的终局信号"转成构造后**立即产生的 J 个局部监督信号**。

### Eq.(6) —— 就地验证


E_j=SEARCH(M_s^(0), q_j) ; ŷ_j=F_{π_a}(q_j, E_j)


- 出处：`p.5` / §4.2 Eq.(6)
- 判据：ŷ_j 相对 y_j 判错即为**失败探针**，作为"M_s^(0) 对当前会话引入的信息不足"的局部证据。

### Eq.(7) —— 修复提案集


R_τ={r_j}_{q_j∈Q_τ^fail}


- 出处：`p.6` / §4.2 Eq.(7)
- 含义：对每个失败探针，反思模块在 (q_j, y_j, ŷ_j, E_j, M_s^(0)) 条件下判断失败性质——是**信息缺失**还是**记忆形态难被检索**——再提出候选修复事实 r_j。

### Eq.(8) —— 语义整合与写回


M_s^*=REFINE(M_s^(0), R_τ)


- 出处：`p.6` / §4.2 Eq.(8)
- 含义：REFINE = 对 R_τ 做**整合（consolidation）**再写回。每个候选事实三选一：`SKIP`（已冗余）/ `MERGE`（补全已有条目）/ `INSERT`（新信息）。
- 关键约束（Prompt 硬规则，`p.24` Table 18）：**不同日期或不同发生次数的同一类活动必须 `INSERT`，绝不 `MERGE`**——只在"完全同一事件、同一时间"时才合并。
- 作用：在写入前**同时**消解"与既有记忆的冲突"和"修复提案之间的冲突"，避免修复反而引入冗余/矛盾。

## 推导链 / 备注

- 这套公式描述的是**"谁在什么条件下产出什么"**的编排契约（policy-style），因此论文里没有数学推导，也没有可微目标。**MemMA 不训练任何参数**——四个角色全是 LLM 调用（或包在既有存储实现外的包装器）。
- 因此"复现"= 复现这套编排与提示词（Prompt 模板见 `p.21–24` Table 12–18），而不是复现训练过程。
- ⚠️ 待核对：Eq.(1) 中检索指导的条件项写作 U_h（查询历史）与 E_h（累积证据）；构造指导的条件项是 M̄_{t-1} 而非 M_{t-1}——**有界视图**这一细节容易漏读，已在 p.4 页面图确认。
