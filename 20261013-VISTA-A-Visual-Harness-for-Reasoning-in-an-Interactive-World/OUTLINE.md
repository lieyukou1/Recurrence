## 一句话结论

用一个极简的"视觉原生" agent harness（原始图像观测 + 无损视觉记忆 + 主动视觉检查工具），把多模态模型**已有**的推理能力释放出来——在 ARC-AGI-3 上把 Claude Opus 5.0 的 RHAE 从 40.68 拉到满分 100.00，且比首次游玩的人类少用 57.4% 的动作。

## 核心贡献

1. **视觉原生交互范式**：把 ARC-AGI-3 从"文本网格 + 代码式世界模型"重新表述为"直接看原始 PNG 图像"的问题，agent 在自然语言里自由推理。
2. **无损视觉记忆（lossless visual memory）**：环境返回的**每一帧**（含中间动画帧）都以原始形式完整存档、按 turn 与 frame 索引，不因上下文压缩/截断而丢失。
3. **主动视觉检查工具（model-directed visual inspection）**：`inspect`（跨空间放大任一矩形区域 / 跨时间取任意历史帧）、`read_pixels`（选定单元格的精确 RGB 值）；配合 `GUIDE.md`（游戏规则长期记忆）与 `WORKING.md`（当前关卡草稿）两层笔记，并在上下文将满时无缝压缩续跑。
4. **极简 + 免程序合成**：harness 纯机械（只负责执行工具、返回图像/像素、报错），不训练模型、不生成符号程序；迁移到新环境（浏览器游戏、静态视觉题、3D 渲染）只需最小改动。

## 方法一句话

把"观察 → 推理 → 行动"循环中的**"观察"换成完整保真的视觉输入**，并挂上一个**可随时主动检索的无损记忆库**，其余交给模型自己用自然语言推理、预测、规划。

## 关键结果

- **ARC-AGI-3（25 个公开游戏）**：Claude Opus 5.0（xhigh）达成 **RHAE 100.00（满分）**，共 7,302 个动作，比首次游玩人类基线（17,135）**少 57.4%**；GPT-5.6 Sol（max）达 99.00。是首个**免程序合成**即达完美/近完美成绩的系统。
- **逐项消融（GPT-5.6 Sol）**：官方文本网格 13.33 → 换成图像观测 47.32 → 放宽动作/时限 51.66 → 连续对话 65.82 → 加笔记 70.05 → **加无损记忆+检查 94.10** → **加像素读取 99.00**。
- **跨环境泛化（GPT-5.6 Sol）**：GameWorld 成功率 63.3% / 进度 79.9%（人类新手 55.3%/64.1%）；AI GameStore 几何均值 140.3（人类中位数归一为 100）；BabyVision 63.2%（官方 41.0%）。
- **开源模型**：GLM-5.3 Flash 320B 用 VISTA 拿到 RHAE 66.93（官方 baseline 仅 1.89）。
